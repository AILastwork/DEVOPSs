sudo apt install ssh — установить SSH (клиент и сервер) в Ubuntu/Debian
ssh-keygen — сгенерировать пару ключей (приватный и публичный .pub)

- Публичный ключ (.pub) — копируем на серверы, к которым подключаемся, в файл ~/.ssh/authorized_keys
- Приватный ключ (без расширения) — остается строго на компьютере, с которого мы подключаемся
-chmod 700 ~/.ssh — доступ к папке .ssh только владельцу
 chmod 600 ~/.ssh/authorized_keys — чтение и запись списка ключей только владельцу

ssh -i ~/.ssh/mykey user@ip_address — подключиться к серверу с указанием конкретного приватного ключа

Чтобы не указывать ключ, логин и IP каждый раз, создаем файл config (без расширения) в папке ~/.ssh/:

Host nas-srv
    HostName 172.19.172.15
    User nas
    IdentityFile ~/.ssh/mykey

После этого подключаемся короткой командой: ssh nas-srv
